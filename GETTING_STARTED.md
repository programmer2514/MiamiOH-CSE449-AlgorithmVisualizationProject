# Welcome to React Router!

A modern, production-ready framework for building full-stack React applications.

## Features

- 🚀 Server-side rendering
- ⚡️ Hot Module Replacement (HMR)
- 📦 Asset bundling and optimization
- 🔄 Data loading and mutations
- 🔒 TypeScript by default
- 🎉 TailwindCSS for styling
- 📖 [React Router docs](https://reactrouter.com/)

## Getting Started

### Installation

Download and install Node v24.1.0.
- Get it directly from [the Node website](https://nodejs.org/en/download)
- Or (Windows only), easily manage Node versions with [NVM for Windows](https://github.com/coreybutler/nvm-windows)

Install the dependencies:

```bash
npm install
```

### Development

Start the development server with HMR:

```bash
npm run dev
```

Your application will be available at `http://localhost:5173`.

## Building for Production

Create a production build:

```bash
npm run build
```

## Deployment

Simply deploy the output of `npm run build` using the static server host of your choice.

```
├── package.json
├── package-lock.json
├── build/
│   ├── client/    # Static assets
```

## Styling

[Tailwind CSS](https://tailwindcss.com/) is already configured for a simple default starting experience.
